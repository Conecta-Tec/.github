# Suporte

Para dúvidas de produto, operação ou acesso, use o canal interno responsável pelo sistema.

Para problemas técnicos:

1. pesquise issues existentes no repositório correspondente;
2. abra uma issue com contexto, impacto, ambiente e passos para reprodução;
3. remova dados pessoais, credenciais e informações confidenciais antes de anexar evidências.

Incidentes de segurança devem seguir a [política de segurança](SECURITY.md).
