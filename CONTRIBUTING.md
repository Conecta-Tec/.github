# Como contribuir

## Fluxo de trabalho

1. Abra ou associe uma issue que descreva contexto, objetivo e critérios de aceite.
2. Crie uma branch curta a partir da branch padrão.
3. Faça mudanças pequenas, testadas e documentadas.
4. Abra um pull request usando o template da organização.
5. Aguarde revisão e checks obrigatórios antes do merge.

## Padrões mínimos

- Não inclua segredos, dados pessoais ou informações de clientes.
- Atualize testes e documentação quando o comportamento mudar.
- Prefira commits claros e pull requests de escopo único.
- Registre decisões técnicas relevantes no próprio repositório.

Cada repositório pode complementar estas regras com orientações específicas.
